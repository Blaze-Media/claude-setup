# Claude setup guides

Setup guides from Blaze Media, written so Claude can follow them. To use one, open the Claude desktop app, start a session in the **Code** tab, and paste:

> Read this page and set it up on my computer: <link to the guide>

## Guides

| Guide | What it sets up |
|---|---|
| [Adobe apps](adobe.md) | Lets Claude work in Premiere Pro, After Effects and Photoshop on your Mac |

These guides point to community projects that are not made or endorsed by Adobe or Anthropic. Save your work before connecting Claude to an app.
